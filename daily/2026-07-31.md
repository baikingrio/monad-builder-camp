
该资产仅用于 Monad Testnet Demo，不具备真实价值、不可兑换。Faucet 暂停只影响新的领取，不影响已经领取的资产、交易、提现或赎回。

## Nuxt 前端进度

前端已从 Vite 页面升级为 Nuxt 4 + Vue 3 的交易终端，并完成第一轮 Monad Testnet 集成。

当前页面包括：

```text
产品首页
+ BTC Target Sprint 交易终端
+ Oddlane Test USDC Faucet
+ Roadmap
+ Order Book / Order Ticket
+ Position / Account
+ Pyth Reference Price 与价格图表
+ Market Lifecycle 状态展示
```

前端加入可选的服务端 Lifecycle Keeper。它先读取合约返回的规范动作，再按需执行排程、锚定、跳过、轮转、结算或作废；价格证明仍由链上合约最终验证。Keeper 默认关闭，生产环境只应在一个常驻 Node 进程中使用独立、低余额的钱包运行。

本地验证：

```text
Nuxt prepare + vitest: 20 passed, 0 failed
production build: passed
```

这次也记录了 Nuxt 的测试前置条件：新环境执行 Vitest 前必须先运行 `nuxi prepare`，生成 `.nuxt/tsconfig.json`。缺少这一步时会出现 TypeScript 配置解析失败，但并不代表业务测试失败。
