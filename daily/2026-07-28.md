## v0.8 的范围冻结

v0.8 不发行可转让 Outcome Token，而使用内部余额：

```text
cashAvailable / cashReserved
aboveAvailable / aboveReserved
belowAvailable / belowReserved
```

市场只维护一个 15 分钟 BTC/USD Target Sprint。订单簿固定为：

```text
99 个价格档
+ 0.01 Share Lot
+ Buy / Sell Above
+ Buy / Sell Below
+ 直接二级交易
+ 互补 Buy 创建 Complete Set
```

核心保护规则：

```text
expiry 后：不能 Place / Match / Complementary Mint
expiry 后：可以 Cancel / 释放 Reserved Balance
Settlement：Pyth 的确定性有效报告，否则 Void
```
