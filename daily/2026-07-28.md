但核心阻塞同样明确：

```text
项目 Resolver 无法独立 Pause 官方 Kuru Market
```


## v0.8 的范围冻结

OddLane 采用内部 Outcome Balance，不为每轮部署可转让 ERC-20 / ERC-1155 Outcome Token：

```text
cashAvailable / cashReserved
aboveAvailable / aboveReserved
belowAvailable / belowReserved
```

核心市场规则固定为：

```text
Buy Above + Buy Below
→ 原子锁定 Test USDC
→ Mint Complete Set

Buy Above ↔ Sell Above
Buy Below ↔ Sell Below
→ 二级交易
```

所有 Place、Match 和 Complementary Mint 路径都必须在 `expiryTime` 前完成；到期后只允许 Cancel、释放 Reserved Balance、Pyth Settlement / Void 与 Redeem。
